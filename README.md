# Shifty Calendar Website

The marketing website for [Shifty Calendar](https://apps.apple.com/us/app/shifty-shift-worker-calendar/id718617321), a delightful shift calendar app for iOS.

## Stack

Plain HTML + [Tailwind CSS](https://tailwindcss.com/) (via CDN). No build step, no dependencies.

## Pages

- **Home** (`index.html`) — App overview and feature showcase
- **Help** (`help.html`) — FAQs and contact information
- **About** (`about.html`) — About the developer
- **Changelog** (`changelog.html`) — Version history and release notes
- **Press Kit** (`press.html`) — Screenshots, features, and media kit download
- **Privacy Policy** (`privacy.html`) — Application privacy policy

## Development

Open any `.html` file directly in a browser, or serve locally:

```sh
python3 -m http.server 8080
```

## Deployment

Deployed via [GitHub Pages](https://pages.github.com/) to [www.shiftycalendar.com](https://www.shiftycalendar.com).
